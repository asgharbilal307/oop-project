#  Social Media App

It* is a console-based social media application developed in **C++** that simulates essential social networking features such as user registration, friend requests, 
private messaging, photo sharing, activity feed, and more. It serves as a foundational structure for building more advanced social platforms amd it includes multiple users.
You can also make a new account if you want

---

## 🌐 Features

### 👤 User Management
- Register new user accounts
- Login/logout functionality
- View and update user profiles
- Password protection and validation

### 🤝 Friend Requests
- Send friend requests to other users
- Accept or reject incoming friend requests
- View friend list
- Unfriend a user

### 💬 Messaging
- Real-time private messaging between friends
- View message history (inbox/outbox)
- Message timestamps

### 📷 Photo Sharing
- Upload photos with captions
- View photo gallery of users
- Like and comment on photos

### 📰 News Feed
- View recent activities from friends
- Feed includes posts, photo uploads, and status updates

### 🔍 Search
- Search users by name or username
- Filter by mutual friends

### ⚙️ Admin Tools (Optional)
- Manage users (block/unblock)
- View platform statistics (active users, uploads, etc.)

---

## 🛠️ Technologies Used

- **Language**: C++
- **File Handling**: Text-based and binary file I/O for data persistence
- **Object-Oriented Programming**: Classes for `User`, `Message`, `Photo`, `FriendRequest`, etc.
- **Optional**: STL containers for internal storage
